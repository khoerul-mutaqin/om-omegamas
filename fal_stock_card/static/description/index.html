STORY BEHIND THE FEATURES

ODOO BEHAVIOR
By default, Odoo’s Inventory module provides reporting tools such as Inventory Valuation to track stock quantities and values, but it does not offer a dedicated Stock Card feature to track detailed stock movements for a specific product over a defined period. Similarly, there is no Stock Summary report to aggregate stock movements.

CLUEDOO BEHAVIOR

This module introduces a Stock Card report, allowing users to track stock movements for a specific product by selecting a start date, end date, product, and location, then clicking Calculate to view quantity changes over the period. Besides, the module provides a Stock Summary report with advanced filtering options.



CLUEDOO RECOMMENDATION

Installation: 100% of company with the inventory apps.

OUR FEATURES AS SOLUTION

Stock Card

Stock Summary

Track your stock movement per location

HOW TO USE THIS MODULE?

STOCK CARD

Go to Inventory → Reporting → Stock Evaluation → Stock Card – Create new, fill in the start date and end date.
Choose the product and the location and then click ‘Calculate’. You can see how the quantity of this product changes during that period

STOCK SUMMARY

On stock summary, we also have options below
Qty<>0: all the products with Start Qty <>0
Period: all the products with stock moves during the period
In Stock: all the products with some quantities in stock
All Products : all the products matching the brand filter, even with zero opening, no movement, or no stock.
